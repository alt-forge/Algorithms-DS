## Сборка и запуск

Общей системы сборки нет. Каждый `.cpp` — самостоятельная программа, кроме поисков: там шаблонные функции без `main`.

```bash
# сортировка (пример)
g++ -std=c++17 -Wall -Wextra "Sorts/Обменные сортировки/bubble sort/bubbleSort.cpp" -o bubble && ./bubble

# Lab1
g++ -std=c++17 -Wall -Wextra -ILabs/Lab1/include Labs/Lab1/src/*.cpp -o lab1 && ./lab1

# Lab2
g++ -std=c++17 -Wall -Wextra -ILabs/Lab2/include Labs/Lab2/src/*.cpp -o lab2 && ./lab2
```
