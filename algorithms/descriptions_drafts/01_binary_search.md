# Бинарный поиск (`binarySearch`)

## 1. Название и классификация

**Бинарный поиск (Binary Search)** --- поиск в отсортированном массиве
методом последовательного уменьшения области поиска вдвое.

-   Класс алгоритма: поиск в упорядоченных данных.
-   Стратегия: «разделяй и властвуй» в итеративной форме.
-   Тип поиска: возвращает индекс найденного элемента или `-1`.
-   Сложность: `O(log N)` по времени.

## 2. Идея

На каждом шаге алгоритм проверяет средний элемент текущего диапазона.

-   Если средний элемент равен искомому значению, возвращается его
    индекс.
-   Если искомое значение меньше среднего, поиск продолжается в левой
    половине.
-   Если искомое значение больше среднего, поиск продолжается в правой
    половине.

Так как массив отсортирован, половину элементов можно исключить после
каждой проверки.

## 3. Входные и выходные данные

**Вход:** - `arr` --- массив целых чисел `std::array<int, N>`,
отсортированный по возрастанию. - `target` --- искомое целое число.

**Выход:** - индекс одного из элементов, равных `target`; - `-1`, если
элемент не найден.

**Условия:** - массив должен быть отсортирован по возрастанию; - пустой
массив допустим; - если значение встречается несколько раз, алгоритм не
обязан возвращать первое вхождение.

## 4. Псевдокод

``` text
left = 0
right = N - 1

пока left <= right:
    middle = left + (right - left) / 2

    если arr[middle] == target:
        вернуть middle
    если target < arr[middle]:
        right = middle - 1
    иначе:
        left = middle + 1

вернуть -1
```

## 6. Анализ сложности

-   Лучший случай: `O(1)` --- элемент найден сразу в середине.
-   Средний случай: `O(log N)`.
-   Худший случай: `O(log N)`.
-   Дополнительная память: `O(1)`.

## 7. Реализация

``` cpp
#ifndef BINARYSEARCH
#define BINARYSEARCH

#include <array>
#include <cstddef>

template <std::size_t N>
int binarySearch(const std::array<int, N>& arr, int target) {
    int left = 0;
    int right = static_cast<int>(N) - 1;

    while (left <= right) {
        int middle = left + (right - left) / 2;

        if (arr[middle] == target)
            return middle;
        else if (target < arr[middle])
            right = middle - 1;
        else
            left = middle + 1;
    }

    return -1;
}

#endif
```

## 8. Примеры использования

``` cpp
#include <array>
#include <iostream>
#include "binary_search.hpp"

int main() {
    const std::array<int, 6> numbers = {2, 5, 8, 12, 16, 23};

    std::cout << binarySearch(numbers, 12) << '\n'; // 3
    std::cout << binarySearch(numbers, 7) << '\n';  // -1
}
```

Индексы начинаются с нуля. В примере число `12` находится по индексу
`3`.
