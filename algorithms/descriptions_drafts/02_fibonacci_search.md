# Поиск Фибоначчи (`fibSearch`)

## 1. Название и классификация

**Поиск Фибоначчи (Fibonacci Search)** --- алгоритм поиска в
отсортированном массиве, который использует числа Фибоначчи для выбора
проверяемых позиций.

-   Класс алгоритма: поиск в упорядоченных данных.
-   Стратегия: последовательное сокращение диапазона с помощью чисел
    Фибоначчи.
-   Тип результата: индекс найденного элемента или `-1`.
-   Сложность: `O(log N)` по времени.

## 2. Идея

Сначала находятся наименьшие числа Фибоначчи, достаточные для покрытия
массива. Затем размер рассматриваемой части уменьшается, а очередной
индекс выбирается на основе чисел Фибоначчи.

-   Если элемент в выбранной позиции меньше `target`, поиск продолжается
    справа.
-   Если он больше `target`, поиск продолжается слева.
-   Если значения равны, возвращается индекс.
-   После основного цикла проверяется оставшийся возможный элемент.

## 3. Входные и выходные данные

**Вход:** - `arr` --- массив целых чисел, отсортированный по
возрастанию; - `target` --- искомое целое число.

**Выход:** - индекс найденного элемента; - `-1`, если элемент
отсутствует.

**Условия:** - массив должен быть отсортирован по возрастанию; - пустой
массив допустим; - при дубликатах не гарантируется первое вхождение; -
реализация с `int` рассчитана на размеры, при которых промежуточные
числа Фибоначчи не переполняют `int`.

## 4. Псевдокод

``` text
fibM2 = 0
fibM1 = 1
fibM = fibM2 + fibM1

пока fibM < N:
    fibM2 = fibM1
    fibM1 = fibM
    fibM = fibM2 + fibM1

offset = -1

пока fibM > 1:
    i = min(offset + fibM2, N - 1)

    если arr[i] < target:
        сдвинуть диапазон вправо
        offset = i
    иначе если arr[i] > target:
        уменьшить диапазон влево
    иначе:
        вернуть i

если оставшийся элемент существует и равен target:
    вернуть offset + 1

вернуть -1
```

## 6. Анализ сложности

-   Лучший случай: `O(1)`.
-   Средний случай: `O(log N)`.
-   Худший случай: `O(log N)`.
-   Дополнительная память: `O(1)`.

## 7. Реализация

``` cpp
#ifndef FIBSEARCH
#define FIBSEARCH

#include <array>
#include <cstddef>

template <std::size_t N>
int fibSearch(const std::array<int, N>& arr, int target) {
    int fibM2 = 0;
    int fibM1 = 1;
    int fibM = fibM2 + fibM1;

    while (fibM < static_cast<int>(N)) {
        fibM2 = fibM1;
        fibM1 = fibM;
        fibM = fibM2 + fibM1;
    }

    int offset = -1;

    while (fibM > 1) {
        int i = offset + fibM2;
        if (i >= static_cast<int>(N))
            i = static_cast<int>(N) - 1;

        if (arr[i] < target) {
            fibM = fibM1;
            fibM1 = fibM2;
            fibM2 = fibM - fibM1;
            offset = i;
        }
        else if (arr[i] > target) {
            fibM = fibM2;
            fibM1 = fibM1 - fibM2;
            fibM2 = fibM - fibM1;
        }
        else {
            return i;
        }
    }

    if (fibM1 &&
        offset + 1 < static_cast<int>(N) &&
        arr[offset + 1] == target) {
        return offset + 1;
    }

    return -1;
}

#endif
```

## 8. Примеры использования

``` cpp
#include <array>
#include <iostream>
#include "fibonacci_search.hpp"

int main() {
    const std::array<int, 6> numbers = {2, 5, 8, 12, 16, 23};

    std::cout << fibSearch(numbers, 16) << '\n'; // 4
    std::cout << fibSearch(numbers, 7) << '\n';  // -1
}
```

Для числа `16` функция вернёт индекс `4`; если числа `7` нет,
результатом будет `-1`.
