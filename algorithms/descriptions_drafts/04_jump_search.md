# Блочный поиск (`jumpSearch`)

## 1. Название и классификация

**Блочный поиск (Jump Search)** --- алгоритм поиска в отсортированном
массиве, который сначала перемещается по массиву блоками, а затем
выполняет линейный поиск внутри подходящего блока.

-   Класс алгоритма: поиск в упорядоченных данных.
-   Стратегия: блочные переходы и линейный поиск.
-   Тип результата: индекс найденного элемента или `-1`.
-   Сложность: `O(√N)` по времени.

## 2. Идея

Размер блока выбирается примерно равным квадратному корню из количества
элементов: `√N`.

Алгоритм проверяет последние элементы блоков:

-   пока последний элемент блока меньше `target`, переходит к следующему
    блоку;
-   когда найден блок, который может содержать значение, линейно
    просматривает его;
-   если совпадение найдено, возвращает индекс; иначе возвращает `-1`.

## 3. Входные и выходные данные

**Вход:** - `arr` --- массив целых чисел, отсортированный по
возрастанию; - `target` --- искомое целое число.

**Выход:** - индекс одного из совпадений; - `-1`, если элемент не
найден.

**Условия:** - массив должен быть отсортирован по возрастанию; - пустой
массив допустим; - при дубликатах не гарантируется первое вхождение.

## 4. Псевдокод

``` text
если N == 0:
    вернуть -1

block = floor(sqrt(N))
prev = 0
step = block

пока следующий блок существует и его последний элемент < target:
    prev = step
    step = step + block

ограничить step значением N

пока prev < step и arr[prev] < target:
    prev = prev + 1

если prev < N и arr[prev] == target:
    вернуть prev

вернуть -1
```

## 6. Анализ сложности

-   Лучший случай: `O(1)` --- подходящее значение обнаружено в первой
    проверке.
-   Средний случай: `O(√N)`.
-   Худший случай: `O(√N)`.
-   Дополнительная память: `O(1)`.

## 7. Реализация

``` cpp
#ifndef JUMPSEARCH
#define JUMPSEARCH

#include <array>
#include <cmath>
#include <cstddef>

template <std::size_t N>
int jumpSearch(const std::array<int, N>& arr, int target) {
    if (N == 0)
        return -1;

    int n = static_cast<int>(N);
    int block = static_cast<int>(std::sqrt(N));
    int prev = 0;
    int step = block;

    while (prev < n &&
           step < n &&
           arr[step - 1] < target) {
        prev = step;
        step += block;
    }

    if (step > n)
        step = n;

    while (prev < step && arr[prev] < target)
        prev++;

    if (prev < n && arr[prev] == target)
        return prev;

    return -1;
}

#endif
```

## 8. Примеры использования

``` cpp
#include <array>
#include <iostream>
#include "jump_search.hpp"

int main() {
    const std::array<int, 6> numbers = {2, 5, 8, 12, 16, 23};

    std::cout << jumpSearch(numbers, 12) << '\n'; // 3
    std::cout << jumpSearch(numbers, 7) << '\n';  // -1
}
```

Число `12` находится по индексу `3`. Числа `7` в массиве нет, поэтому
результат --- `-1`.
